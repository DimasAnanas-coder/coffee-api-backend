# Учёт заказов кофейни

Небольшой REST API на FastAPI для создания и управления заказами. Пользователи и заказы хранятся в PostgreSQL.

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Активируйте виртуальное окружение, затем установите зависимости:

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, чтобы при необходимости изменить настройки, и запустите сервер:

```bash
fastapi dev app/main.py
```

Интерактивная документация доступна по адресу <http://127.0.0.1:8000/docs>, альтернативная — <http://127.0.0.1:8000/redoc>.

## Настройки

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `APP_NAME` | `Учёт заказов кофейни` | Название сервиса и заголовок документации |
| `DATABASE_URL` | `postgresql+psycopg://user:password@localhost:5432/coffee_db` | URL подключения к PostgreSQL |
| `DEFAULT_PAGE_SIZE` | `10` | Размер страницы, если `limit` не передан |
| `MAX_PAGE_SIZE` | `50` | Максимальное значение `limit` |

## Эндпоинты

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Приветственное сообщение |
| `GET /info` | Название сервиса и количество заказов |
| `POST /orders` | Создать заказ; возвращает `201` |
| `GET /orders` | Список заказов; поддерживает `status`, `limit` и `offset` |
| `GET /orders/{order_id}` | Получить заказ по идентификатору |
| `PATCH /orders/{order_id}` | Обновить только переданные поля заказа |
| `DELETE /orders/{order_id}` | Удалить заказ; возвращает `204` без тела |

Статусы заказов: `pending`, `ready`, `completed`. Сумма должна быть положительной. При обращении к отсутствующему заказу возвращается `404`.

При создании заказа нужно передать положительный `user_id` и сумму `amount`. Пользователь с таким ID должен существовать в базе.

### Пример создания заказа

```json
{
  "user_id": 1,
  "amount": "120.00"
}
```

Новый заказ получает статус `pending` автоматически.
